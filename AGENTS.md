# Agents

## Line length

* Every line is at most 80 characters: documents, commit messages
  (subject and body), and command help text. Wrap, don't overflow.

## Commits

* No `Co-Authored-By: Claude` or other AI attribution lines in commit
  messages. Most work is done with agents anyway, so the line is just
  noise. Write a clear subject line and a short body when needed.
