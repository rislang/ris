# Design and language references

These snapshots let ris cite upstream rules without duplicating them.

* [iyi](iyi/README.md): inherited language, compiler and library behaviour.
* [Goose](goose/README.md): tape memory, owners, roots and pool design.

Each snapshot records its exact source revision and includes its licence.
Source copies remain unchanged and are exempt from ris document limits.
Snapshots may differ from current upstream or ris implementations; consult
their version notes. ris's [tape spec](../../TAPE_SPEC.md) and
[agent rules](../../AGENTS.md) define ris-specific behaviour.

Link to the relevant source section when it still applies. Write only the
ris-specific differences in ris docs; importing a design does not adopt it.
